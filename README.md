# WOWGPT 🤖

WOWGPT is a full-stack AI-powered chat application that provides an interactive conversational experience with a clean and responsive interface. The project is built using modern web technologies with separate frontend and backend architecture.

## 🚀 Features

- User-friendly chat interface
- Real-time conversation experience
- Authentication system
- Backend API integration
- Responsive design
- Secure environment variable handling
- Modular frontend and backend structure

## 🛠 Tech Stack

### Frontend
- ReactJS
- JavaScript
- CSS
- Vite

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Axios

## ⚙️ Installation

Clone repository:

```bash
git clone https://github.com/Kiranthr/WOWGPT.git
```

Move into project:

```bash
cd WOWGPT
```

Install frontend dependencies:

```bash
cd Frontend
npm install
```

Install backend dependencies:

```bash
cd ../Backend
npm install
```

## ▶️ Run Application

Backend:

```bash
npm start
```

Frontend:

```bash
npm run dev
```

## 🔐 Environment Variables

Create a `.env` file inside Backend:

```env
MONGO_URI=your_database_url
JWT_SECRET=your_secret
API_KEY=your_api_key
```
